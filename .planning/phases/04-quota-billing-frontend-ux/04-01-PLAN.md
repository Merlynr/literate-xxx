# Phase 4 Plan 01: Quota Ledger, Pricing Plans, and Billing APIs

## Must Haves

- Freeze quota when a generation job is created.
- Deduct quota only after the job succeeds.
- Release frozen quota when the job fails.
- Store pricing plans as editable data, not constants.
- Expose a quota summary API that the frontend can use on home and my pages.
