<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BFF worker -> DashScope | Server-side provider calls cross into an external AI API and return transient URLs. |
| BFF worker -> OSS | Raw and watermarked outputs are uploaded as canonical storage objects. |
| Worker -> Database | Job state and event updates must remain consistent even when the provider fails or retries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | D | worker provider calls | mitigate | Keep the Celery hard/soft time limits in force, retry only transient failures, and fail the job cleanly when DashScope hangs or times out. |
| T-03-05 | T | prompt assembly | mitigate | Assemble prompts only from frozen snapshots and never re-read live promo rule rows inside the worker. |
| T-03-06 | I | result persistence | mitigate | Download the provider URL immediately, store only OSS keys in the database, and return short-lived signed URLs on demand. |
</threat_model>
