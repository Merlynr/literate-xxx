## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mini program UI -> BFF API | User input, file metadata, and retry state are untrusted until validated by the backend. |
| generation store -> rendered result | Signed URLs and status values are trusted only after the backend returns them. |
| test harness -> FastAPI app | Contract tests must not bypass auth, tenant scoping, or endpoint routing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | T | generate page inputs | mitigate | Only send confirmed asset ids, selected category/style ids, and client_request_id from the store; never send raw OSS keys from the UI. |
| T-03-08 | I | result rendering | mitigate | Render the watermarked image by default, keep raw download secondary, and consume only tenant-scoped signed URLs from the backend. |
| T-03-09 | D | retry and contract tests | mitigate | Preserve state across retries and assert idempotent job creation so the same `client_request_id` cannot fan out into duplicate jobs. |
</threat_model>
